# What's this?

YumLife was a mod for OHOL and AHAP based on [hetuw](https://github.com/hetuw/OneLife).

# Why not anymore?

I'd recommend watching [Twisted's video](https://www.youtube.com/watch?v=NZo2jWzCtfU&pp=ugUEEgJlbg%3D%3D) on the OHOL community situation.

In short, I don't feel comfortable supporting the OHOL developer either.

I really intended for this to be a "forever project" to ensure there was always an active OHOL mod of some kind. I'm sorry that I couldn't follow through on that.
